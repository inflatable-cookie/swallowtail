## Why It Matters

Ollama's native API accepts `options.num_ctx` to select a request context
window, but Swallowtail currently exposes only output, reasoning, and structured
output controls. Consumers cannot make that exact local-runtime selection
through the prepared facade.

The safe boundary is narrower than a generic context control. `num_ctx` is a
runner option that may load or reload a model, alter memory pressure, be capped
by model/runtime behavior, or contribute to eviction on an externally owned
runtime. This run must preserve that provider truth, keep the value
Ollama-local, and claim only exact qualified dispatch.
