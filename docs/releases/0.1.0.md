# Swallowtail 0.1.0 Release Candidate

Status: active non-published candidate
Date: 2026-07-25
Registry target: crates.io

This candidate replaces the superseded compile-only candidate. It makes
adapter-local prepared facades and typed bound operations the normal public
path for all 22 production routes. Low-level driver roles remain public for
profiles the prepared facade does not express. No external release state
changed.

## Rust API Compatibility

There is no prior published Swallowtail version. This replacement therefore
creates the initial pre-1.0 API and guaranteed-behavior baseline.

Compared with the superseded candidate source
`6c0e8d9b5b05e9db0f655527491d47aa18d246f8`, deterministic public-
declaration hashes changed for 20 packages: core, runtime, local host, testkit,
and all 16 adapters. The ACP protocol, OpenAI-compatible chat protocol, and
remote ACP transport hashes are unchanged. The delta is candidate-breaking:
the incomplete pre-publication baseline is replaced rather than shimmed or
versioned as a released compatibility line.

Before 1.0:

- compatible changes advance the patch
- breaking Rust API or guaranteed-behavior changes advance the minor
- provider-range changes remain a separate compatibility axis

The public-declaration baseline is a deterministic change detector. It does not
replace maintainer SemVer classification.

Ordered stable releases above a claim's latest-qualified boundary may execute
only where that driver explicitly permits visible unverified-newer operation.
They are not guaranteed support. Gaps, exclusions, incompatible older
versions, malformed versions, and unqualified prereleases remain closed.

Hosted APIs without a release-version axis use their exact dated protocol,
access, route, lifecycle, and fixture boundaries. A Swallowtail package version
does not imply endpoint access, credentials, entitlement, billing, model
availability, provider support, or sandboxing.

The exact route, prepared path, access boundary, version posture, and low-level
escape hatch for every production driver are recorded in the
[provider route matrix](../guides/provider-route-matrix.md).

## Known Limits

- exact crates.io name availability, account, token, owner, and team state must
  be checked at the publication gate
- Effigy's generic single-package release planner does not model this virtual
  23-package staged workspace
- no target beyond Apple Silicon macOS is verified
- no Rust toolchain outside the declared floors and current stable is verified
- live provider authentication and installed-runtime probes remain separately
  gated
- stable provider or harness releases above an explicitly qualified upper
  bound are mileage-may-vary where that driver permits visible
  unverified-newer execution; they are never silently guaranteed
