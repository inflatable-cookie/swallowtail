truth. Verbosity is useful only when Swallowtail can bind what the selected
Codex model and provider actually support. A config-schema enum alone does not
prove model support; a model-name prefix does not prove the current metadata;
and dispatch does not prove provider acceptance or effective response length.

suppresses user config, chooses one model explicitly, and owns one child. The
worker must preserve that boundary: closed adapter-local input, immutable
evidence, exact child argv, unchanged omission, and rejection before effects
for unsupported or drifting rows.
