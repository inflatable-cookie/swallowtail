## Source Boundary

Exact `0.30.0` is byte-identical to `0.29.2` across the selected local-server
surface. Exact `0.31.0` keeps REST routes, WebSocket v2 control and event
schemas, cursor behavior, and lifecycle operations unchanged.

The broadcaster now folds full legacy status into every agent status event and
resolves the derived secondary model to a display alias when possible. This
repairs provider UI state. Swallowtail already maps the event to progress and
does not disclose those fields, so the delta needs a behavior milestone and
corpus rather than a new portable capability.
