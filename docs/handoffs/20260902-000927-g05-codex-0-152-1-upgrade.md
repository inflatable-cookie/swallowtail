## Acceptance

The PR is acceptable when:

1. The first commit freezes exact official `0.152.1` identity and complete
   artifact/protocol evidence while every production Codex ceiling remains
   `0.152.0` and `0.152.1` remains `UnverifiedNewer`.
2. npm/GitHub/package/platform identities reconcile. The published stable hop
   set from `0.152.0` is exact; alpha releases are excluded; historical gaps
   remain incompatible; a real unpublished later point is tested.
3. Complete tree comparison is deterministic. Changed files feeding mapped
   behavior are fully inventoried and classified; byte-identity claims use
   exact digests; changelog prose is never the completeness oracle.
4. Exec and app-server are assessed separately but remain one ordered
   `codex.cli` family. No result is flattened onto feature-specific, TUI, MCP,
   Guardian, hosted OpenAI, or code-mode surfaces.
5. Every exact/universal/negative claim has a mutation-sensitive proof:
   corrupting an artifact digest, file/key set, selected method/field/help flag,
   gap, route axis, or identity-before-claim boundary fails.
6. If the mapped subset is unchanged, the second commit extends both applicable
   maintained segments and the shared latest-qualified constant to `0.152.1`,
   keeps `AllowUnverified`, preserves claim/behavior revisions unless Contract
   029 requires a revision, and updates only current downstream truth.
7. If mapped wire, lifecycle, failure, permission, usage, capability,
   session-update, config/mode, or session-operation behavior changed beyond a
   compatible extension, the worker stops after identity and reports the exact
   milestone or public-facade decision needed.
8. g05.009/card 034, 249/518, watcher, Gemini deferral, and every second family
   remain untouched.

## Stop Conditions

Stop after identity and report evidence when:

- npm, GitHub, package, platform, or binary identity disagrees;
- official latest moves after evidence repair or before final push;
- exact artifact identity cannot be corroborated from primary sources;
- the selected mapped subset changes in a way requiring a new private behavior
  revision, driver, facade, public operation, or operator policy;
- qualifying `0.152.1` needs a provider prompt, live session, install, host
  mutation, or execution of a downloaded binary;
- the result would weaken an existing gap or feature-specific exact bound
  without its own accepted evidence;
- any validation result changes the planned segment shape.
