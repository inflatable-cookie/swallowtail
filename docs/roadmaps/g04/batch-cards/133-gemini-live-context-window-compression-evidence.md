## Method

1. Freeze current official Live WebSocket, exact-model, session-management,
   and best-practices pages for `gemini-3.1-flash-live-preview`,
   `BidiGenerateContentSetup.contextWindowCompression`,
   `ContextWindowCompressionConfig`, `SlidingWindow`, `triggerTokens`, and
   `targetTokens`. Record retrieval dates, page dates, stable URLs, and
   specimen digests.
2. Freeze current route source and deterministic fixtures for model, endpoint,
   facade axis/point, private behavior, initial and resume setup, prepared
   input, plan/evidence, driver, selected thinking, output maximum, latest
   resumable handle, rollover, and fresh restoration.
3. Classify exact omission, `{ "slidingWindow": {} }`, trigger-only,
   target-only, and explicit trigger/target shapes. Close JSON integer form,
   accepted numeric domain, target/trigger ordering, provider defaults, zero,
   negative, fractional, overflowing, partial, aliased, and unknown forms.
   Official examples are evidence, not permission to infer missing bounds.
4. Distinguish provider-described sliding-window behavior from observable
   adapter truth. Record turn-boundary eviction, retained-prefix statements,
   and usage metadata only to the extent exact official sources support them.
   Setup completion has no fields and proves no applied configuration.
5. Prove omission retains the prior initial and resume setup bytes. Prove
   whether one selected config can remain immutable across initial setup,
   provider-planned rollover/resume setup, and fresh working-state restoration.
6. Prove composition with omitted and every admitted thinking level plus
   omitted and every admitted output maximum without changing either control.
7. Decide the exact opaque facade point, private behavior revision, claim id,
   and model-route revision. Retain prior points as frozen superseded proof.
8. Replace Research 195's reservation with exact shape/value dispositions and
   a deliver-now table. Do not edit production code or shared closeout surfaces.

No credential, account inspection, provider request, paid operation, browser
