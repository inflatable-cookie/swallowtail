# 090 v0.4.0 To Candidate Compatibility Audit

Status: ready
Owner: Tom
Created: 2026-09-05
Updated: 2026-09-05
Milestone: `../030-v0-4-1-release-readiness.md`
Depends on: Contract 036; immutable `v0.4.0` at `56f3913a`; card 050 as precedent; cards 080 and 034 merged

## Goal

Prove that everything on `main` since `v0.4.0` is patch-compatible, freeze
the `0.4.1` release census, and classify every change, so card 091 prepares
the candidate from evidence rather than assumption.

## Scope

1. Fetch canonical GitHub without changing source. Record remote, branch,
   audited head, the `v0.4.0` tag object and peel, merge base, commit and
   changed-file counts, and the full `v0.4.0..HEAD` inventory.
2. Confirm no open mergeable feature or currentness PR exists.
3. Reconcile the 40-package graph and every production route at the audited
   head with the immutable `v0.4.0` baselines: 40 packages, 49 routes.
   OpenCode's qualified range moved to `1.18.28`; record it as a Contract 029
   qualification, not a package change.
4. Generate current semantic Rust API evidence with the Contract 036
   toolchain into temporary output. Compare all 40 packages with the
   immutable `public-api-0.4.0` baseline and with the additive baseline
   files regenerated by cards 068, 069, 073, 074, 075, 079, 080, and 034.
5. Audit source, changelog, contracts, architecture, guides, matrices, logs,
   and tests for guaranteed-behaviour changes since `v0.4.0`. Pay explicit
   attention to: the card 089 preflight scoping (a widening; plans that
   previously failed now pass, no plan that passed now fails); the
   `claude-agent.sdk` default profile (must be behaviourally identical);
   Contract 013 and 061 amendments; and every Contract 061 tranche.
6. Produce a package-by-package semantic API ledger and a
   route/guaranteed-behaviour ledger with evidence, compatibility class,
   consumer effect, and changelog coverage per item; explicit negative
   evidence per unchanged package and route.
7. Confirm patch `0.4.1`, 40 packages, 49 routes, Rust `1.95.0`, Apple
   Silicon macOS, and source-only annotated-tag intent. Run read-only
   release status and record the inferred version.
8. Add Research 286 with the ledgers. Fill this card's `## Result`. Stop.

## Out Of Scope

Version bumps, changelog promotion, lock sync, baseline regeneration, tag
work, provider contact, consumer edits, any Rust change.

## Acceptance Criteria

- [ ] every public item and guaranteed value changed since `v0.4.0` appears
      in a ledger with a class and evidence
- [ ] immutable `v0.4.0` baselines are byte-identical
- [ ] read-only release status infers `0.4.1`, or the stop names the break
- [ ] the `claude-agent.sdk` default profile is proved unchanged

## Validation

- `effigy package:api`
- `effigy qa:routes`
- `effigy qa:docs`
- `effigy qa:northstar`
- `git diff --check`

## Review Oracle

Invariant: one exact tree supports every compatibility statement. Smallest
counterexample: a changed public item or guaranteed value absent from the
ledger, or a break classified compatible.

## Auto-Continuation

No. Stop for exact-head review; card 091 needs separate operator prepare
authorization.

## Stop Conditions

Any breaking change; a modified immutable baseline; an open mergeable
feature or currentness PR; release status inferring anything but `0.4.1`.

## Result

Complete at audited head `2187bbecb9e24425f574f4c6c434fd8f16fe0300`.
The v0.4.0-to-head range is patch-compatible: 40 packages, 49 production
routes, 120 commits, 361 changed paths, 88 unchanged internal dependency
edges, and no route additions or removals. The semantic API audit found 244
additive reference lines across 14 package files and 0 removals; the other 26
packages are byte-identical to the v0.4.0 tag output. Contract 061 tranches
are additive, Card 089 is a widening scoped to ambient profiles, the
`claude-agent.sdk` default profile is behaviorally identical, and OpenCode
`1.18.28` is a Contract 029 qualification only. Frozen tag baseline paths
match byte-for-byte; current API references retain the tag bytes plus authorized
additions. Read-only release status is ready for patch `0.4.1`; no stop
condition was present. Research 286 and its index line contain the package,
route, behavior, baseline, release, and full-range ledgers. Named validation
passed: `effigy package:api`, `effigy qa:routes`, `effigy qa:docs`,
`effigy qa:northstar`, and `git diff --check`. Exact-head PR handoff is
next.
