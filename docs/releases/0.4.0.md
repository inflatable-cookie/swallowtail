# Swallowtail 0.4.0

Status: candidate; not tagged
Distribution: intended annotated Git tag `v0.4.0`
Registry: not published
GitHub Release: not created

`v0.4.0` is a coordinated pre-1.0 minor over immutable `v0.3.3`. Contract 036
requires the minor because current source removes the previously guaranteed
OpenAI Background `minimal` reasoning value and changes the shared interactive
close signature and cleanup boundary. The package set stays 40. The candidate
route inventory is 49: the immutable `v0.3.3` 47-route release inventory plus
`pi.sdk-sidecar` and `claude-agent.sdk`. Rust `1.95.0`, Apple Silicon macOS,
`publish = false`, and source-only distribution are unchanged.

This note describes the prepared source candidate awaiting exact-head review
and canonical merge. Preparation does not authorize `effigy release execute`,
tag creation, tag push, crates.io publication, a GitHub Release object,
binaries, sidecars, or installers. Card 052 consumer and authenticated
application proof remains a later, separately authorized step.

## Install

After the candidate is tagged, use the canonical repository and same exact tag
for every direct dependency:

```toml
[dependencies]
swallowtail-core = { git = "https://github.com/inflatable-cookie/swallowtail", tag = "v0.4.0" }
swallowtail-runtime = { git = "https://github.com/inflatable-cookie/swallowtail", tag = "v0.4.0" }
swallowtail-host-local = { git = "https://github.com/inflatable-cookie/swallowtail", tag = "v0.4.0" }
swallowtail-adapter-codex = { git = "https://github.com/inflatable-cookie/swallowtail", tag = "v0.4.0" }
```

Never mix tags, branches, paths, registry placeholders, or unreviewed revisions
in one consumer graph.

## Breaking

These are the Card 050 classified breaks. There is no compatibility shim.

- Interactive close: `InteractiveSessionHandle::close` now requires exact
  `HostServices` and a `SessionCleanupRequest` with one caller-selected
  absolute deadline. The deadline covers active-turn interruption, escalation,
  task and pump joins, credential release, and resource release. Expiry,
  cancellation, and a dropped cleanup future report failed or unconfirmed
  cleanup rather than an unbounded or falsely clean close. The zero-argument
  close is removed. This is a coordinated public API and cleanup-boundary
  change on `swallowtail-runtime` and all 25 current
  `InteractiveSessionDriver` routes. Update every close caller. Rollback to
  `v0.3.3` restores the old close call and cannot mix workspace versions.
- OpenAI Background `minimal`: exact GPT-5.6 `openai.background` preparation
  no longer admits the previously guaranteed but unqualified `minimal`
  reasoning value. Admitted values are `none`, `low`, `medium`, `high`,
  `xhigh`, and `max`. `minimal` fails before endpoint, credential, request, or
  provider work. The corrected opaque facade point is
  `openai-responses-background-2026-08-23` with private behavior revision
  `openai.responses-background-v2`. Replace `minimal` or fail closed. Rollback
  restores historical `v0.3.3` behavior only.
- Selected-tier checkpoints: OpenAI Background selected-tier checkpoint
  restart reconciliation is rejected before network work. Explicit default-tier
  dispatch remains ordinary attached and one-reattachment only. Do not restart
  selected-tier checkpoints. Rollback returns to `v0.3.3` only.
- `kimi-code.acp` range: `QualifiedOnly` ends at `0.38.0`. Exact `0.39.0` and
  `0.39.1`, unpublished `0.38.1`/`0.39.2`, and farther `0.40.x` fail closed
  because the newer terminal path creates an uncontained local process. Stay at
  `0.38.0` or stop. Rollback does not justify mixing the old `AllowUnverified`
  posture with current source.

## Added Routes And Lifecycle

- `pi.sdk-sidecar` is a qualified exact `@earendil-works/pi-coding-agent`
  `0.84.2` route through the application-provisioned Node `22.23.2` runtime,
  source-tagged sidecar, and private `swallowtail-pi-sdk-jsonl-v1` wire. New,
  load, and resume use the exact host-leased cwd with bounded typed replay on
  load, durable app-owned session state, no archive/restore/delete, and no
  substitution for `pi.rpc`. New consumers provision those exact runtime,
  sidecar, wire, SDK, and session-directory axes. Existing `v0.3.3` consumers
  have no action unless opting into the new route. Rollback reverts to
  `v0.3.3`, omits the route and sidecar calls, and does not mix workspace
  versions or alias `pi.rpc`.
- `claude-agent.sdk` is a Unix-only exact `@anthropic-ai/claude-agent-sdk`
  `0.3.259` route, carrying native `2.1.259`, through a source-tagged Node
  sidecar (exact Node `22.23.2`) over private
  `swallowtail-claude-agent-sdk-jsonl-v1` at behavior revision
  `claude-agent.sdk-v1`. Five qualified-only one-point axes bind the SDK
  wrapper, native binary, runtime, wire, and sidecar revision independently; no
  ACP or Claude Code claim transfers. The application provisions the runtime,
  SDK entry, peer dependencies, and platform package. Swallowtail holds no
  subscription credential: it leases a delegated reference, admits only
  `firstParty` provenance with an `oauth` key source, and forbids
  credential-bearing `/bridge` and `/browser` subpaths. Reserved reaping
  precedes credential, resource, process, and provider effects. One guardian
  owns pump, process, and leases. Close reports `Clean` only on
  `ProcessTreeCompletion::OwnedTreeEmpty`; ordinary macOS confirmed root
  completion after descendant termination is `Degraded`; a surviving descendant
  or unconfirmed root is `Failed`. Session persistence is disabled. Windows is
  `Unsupported`. `AcceptedForReap` is ownership transfer, never join or cleanup
  completion. Opt in only at the exact axes. Rollback to `v0.3.3` removes the
  route; never alias it to ACP or Claude Code.
- Reserved reap (`TaskReapReservation`, `reserve_reap`, `spawn_reapable`) and
  scoped-task relinquishment are additive. Ordinary unreserved spawn, explicit
  join, and join-on-drop stay unchanged.
- Process-tree evidence distinguishes `RootOnly` from `OwnedTreeEmpty`.
  Host-local remains root-only under ordinary macOS authority. Consumers cannot
  infer descendant cleanup from root exit.

## Upgrade And Rollback

To upgrade, change every direct dependency to `v0.4.0` in one edit, update the
consumer lock file, and confirm every Swallowtail package resolves from the
same tag. Then:

1. pass exact host services, cleanup request, and absolute deadline to every
   `InteractiveSessionHandle::close`; handle failed or unconfirmed cleanup
2. replace OpenAI Background `minimal` with an admitted value, or accept
   fail-before-effects rejection
3. do not restart selected-tier OpenAI Background checkpoints
4. keep `kimi-code.acp` at `0.38.0` or stop; do not import `0.39.x` ACP
5. select Kimi headless v1/v2 by the corrected provider-version split
6. provision Claude SDK or Pi SDK sidecar only when opting into those routes,
   at their exact runtime, sidecar, wire, SDK, and session-directory axes

To roll back, restore every direct dependency to `v0.3.3` and restore the
previous lock file in the same change. Rollback restores the old close call and
historical `minimal` behavior, omits the two new routes and their sidecar
calls, and drops reserved-reap and tree-attestation APIs. Never mix workspace
versions, alias `pi.sdk-sidecar` to `pi.rpc`, or alias `claude-agent.sdk` to
ACP or Claude Code. Never move or recreate either tag.
