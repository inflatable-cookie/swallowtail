## Change

Public capability truth now separates provider-session catalogue from explicit
import. The provider feature CSV remains provider-sorted and reports support
only for the production Codex app-server, Kimi ACP, and OpenCode HTTP solution
rows. The route matrix publishes all 19 split-route classifications and exact
promotion gates.

A central guide defines the prepared browse, select, import, load/replay, and
resume flow. It keeps management and consumer persistence separate and rejects
raw-id attachment, scope widening, account or filesystem scans, and automatic
synchronization. Codex, Kimi, and OpenCode examples expose only prepared,
validated operations.
