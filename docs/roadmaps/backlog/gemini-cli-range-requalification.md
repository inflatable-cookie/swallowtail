# Gemini CLI Range Requalification

Status: deferred
Owner: Tom
Source: superseded g03.002 and card 006

## Deferred Work

Reassess Gemini CLI's ACP and headless guarantees above their current exact
bounds. Existing Gemini production support remains unchanged.

This is deferred rather than paused. Antigravity now owns Swallowtail's active
personal-Google harness route. The installed Gemini API-key route authenticated
but returned no response to an operator prompt, so there is no current
consumer-value reason to schedule near-term range work.

## Promotion Gate

Promote only when at least one is true:

- a consumer needs Gemini's enterprise or paid API-key harness route
- reproducible evidence shows the installed route is useful under its supported
  access posture
- Google materially changes the Gemini and Antigravity access boundary
- Gemini exposes a capability not covered by Antigravity and worth a separate
  maintained route

Promotion must revalidate current official artifacts, both independent route
axes, authentication authority, and provider response readiness. There is no
Gemini-to-Antigravity fallback and no implied revisit date.
