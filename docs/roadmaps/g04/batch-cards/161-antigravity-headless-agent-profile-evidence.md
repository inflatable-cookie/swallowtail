## Goal

Freeze the exact Antigravity CLI agent-profile surface and define the smallest
version, operation, and profile-id set that can be dispatched and confirmed
without widening the current prepared route's authority.

## Method

1. Freeze current official Antigravity CLI `1.1.17` headless, agents-command,
   permission, and reference documentation with retrieval dates and complete
   specimen digests.
2. Inspect exact qualified `1.1.9..=1.1.17` help, published artifacts/source
   where available, and existing identity fixtures. Record where `--agent`,
   `agent`/`agents`, and `init.agent` first exist and whether semantics drift.
3. Freeze the complete bounded `agy agents` output shape: id/display columns,
   whitespace, ordering, duplicates, empty result, stderr, exit, size, custom
   profile visibility, and authentication/account dependence. Do not capture
   account identifiers, credentials, profile bodies, instructions, or paths.
4. Freeze exact `--agent <id>` parsing and one invalid/unavailable profile
   outcome. Determine whether any missing value, alias, display label, or stale
   id silently falls back.
5. Freeze a selected stream-JSON `init` specimen and prove whether `init.agent`
   is exact effective confirmation before accepted output. Keep model,
   permission mode, cwd, tools, and schema validation independent.
6. Classify structured run, first continuation child, exact-id subsequent
   child, and fresh replacement separately. Decide whether every child must
   reassert the profile and whether the same id is confirmed.
7. Classify composition with explicit model, `low|medium|high` effort, JSON
   Schema, `ResourceAccess::Read` plan mode, read-write, ambient isolation,
   provider sandbox, deadline, cancellation, terminal errors, and cleanup.
8. Define a bounded route-local profile-id type only if exact evidence supports
   it. Distinguish installation-observed ids from values Swallowtail can claim
   portable or qualified.
9. Decide exact qualified and `UnverifiedNewer` inheritance plus behavior,
   driver, claim, matrix, and configured-instance revision posture.
10. Replace Research 205's reservation with source-backed evidence and a
    deliver-now table or honest empty set.

Current official public documentation, public exact artifacts/source, existing
fixtures, and secret-free promptless help/listing are authorized. Do not
install or authenticate Antigravity, mutate account/config/profile state,
capture credentials or account identity, send a provider prompt, or perform
paid work.

host-local unstable listing, missing selected `init.agent` fixture, unproved

## Stop Conditions

- agent ids cannot be bounded without reading private profile bodies or paths
- selection can silently fall back or lacks exact `init.agent` confirmation
- selected profiles bypass or widen current access, permission, or isolation
- continuation semantics require ambient latest-session lookup or unconfirmed
  inherited profile state
- qualification needs login, account mutation, provider prompt, generic
  configuration, a contract change, or currentness movement

## Out Of Scope
