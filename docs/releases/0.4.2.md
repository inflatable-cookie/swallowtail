# Swallowtail 0.4.2

Status: candidate; not tagged
Distribution: source-only candidate
Registry: not published
GitHub Release: not created

`0.4.2` is a coordinated pre-1.0 additive patch candidate over the tagged
`v0.4.1`. It carries the Claude Agent SDK open-path repair, the final Contract
061 contribution tranches, and deterministic release-lane fixture repairs. No
tag, publication, GitHub Release object, binary, sidecar, installer, or
consumer-repository mutation is part of this candidate.

## Install

If the operator authorizes the tag, use the canonical repository and the same
exact `v0.4.2` tag for every direct dependency:

```toml
[dependencies]
swallowtail-core = { git = "https://github.com/inflatable-cookie/swallowtail", tag = "v0.4.2" }
swallowtail-runtime = { git = "https://github.com/inflatable-cookie/swallowtail", tag = "v0.4.2" }
```

Do not mix tags, branches, paths, registry placeholders, or unreviewed
revisions in one consumer graph. Before adoption, an external source consumer
must resolve every direct dependency from the same exact tagged source.

## Upgrade And Rollback

To upgrade after tagging, change every direct Swallowtail dependency to
`v0.4.2` in one edit, update the consumer lock file, confirm every Swallowtail
package resolves from that same exact tag, and run the deterministic consumer
checks. The new Claude SDK diagnostics and Contract 061 contributions are
additive or opt-in; the default SDK profile remains unchanged.

To roll back, restore every direct dependency to `v0.4.1` and restore the
previous lock file in the same change. Do not mix workspace versions or
untagged revisions.
