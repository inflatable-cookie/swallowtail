`0.5.2` is a coordinated pre-1.0 patch over tagged `v0.5.1`. It carries only
the reviewed Claude Agent SDK lease and usage fixes and the tested sender
registration versus pump-failure close-race repair. Other provider/runtime
qualified points, routes, and guarantees remain at their released values.
The sole dependency exception is the minimum compatible Rustls security fix
required by RUSTSEC-2026-0285, detailed below.

## Correction

The SDK registered-tool lease now survives the session-open deadline until
session close. Each tool call keeps its own maximum duration, and an explicitly
provided lease deadline still bounds calls. Existing operation-scoped callers
retain their previous default. Close also prevents a command sender from
registering a pending reply after pump failure has drained pending replies.

The sidecar projects the SDK's four per-turn input, output, cache-read, and
cache-creation counters through existing `TokenUsage` and
`ProviderObservation::Usage` records with truthful usage provenance. It does
not emit cumulative `modelUsage`. The SDK has a separate context-occupancy API,
but this patch adds no context-usage field and does not infer occupancy from
per-turn totals.

The route remains bound to Claude Agent SDK `0.3.259`, native binary `2.1.259`,
Node `22.23.2`, and wire
`swallowtail-claude-agent-sdk-jsonl-v1`. The coordinated source package moves
to `0.5.2`; the sidecar source tag is derived from that package version and the
embedded bytes come from the matching source file. No SDK/native/Node pin,
route qualification, or provider claim is changed.

## Mandatory Hosted CI Corrections

Hosted candidate CI exposed two compatibility assumptions and two Rust 1.95
lint findings after the first candidate review. The registered-call deadline
calculation now returns its bounded deadline expression directly, with the
same saturating duration bound. Session cleanup retains its must-use promise
with an explicit reason to poll the returned future.

The wire-v1 decoder accepts legacy `turn_ended` records that omit usage, as in
the frozen exact-SDK `0.3.259` corpus. It emits no usage observation when that
additive field is absent and still rejects malformed usage when present. The
real candidate sidecar continues to project the four validated per-turn
counters. Deterministic fake SDK producers now use that released result shape
for successful turns; the frozen corpus and stdio mediation contract were not
changed or rebaselined. The candidate regression selector includes both the
qualified corpus decode and the real Swallowtail sidecar stdio mediation test,
for 24 bounded regressions total (5 runtime, 1 host-local, 18 adapter).
