## Current Baseline

optional provider-native schema, read-plan mode, optional provider sandbox, and
exact conversation id. It does not pass `--agent`. The parser requires exact
model and `permission_mode=request-review` but does not inspect `init.agent`.
Continuation starts one child per turn and reasserts the model.

Current official docs say `agy agents` lists available agents, `--agent`
selects one for a headless run, and `init.agent` appears when selected. Those
statements are planning leads, not qualified values or behavior.
