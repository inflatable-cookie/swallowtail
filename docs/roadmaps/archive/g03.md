## Intent and boundary

Keep Swallowtail useful across real provider and harness release ranges while
hardening consumer-proven defects — without chasing every upstream release.
Each release carries its qualified ranges; above-ceiling versions stay
unverified-newer unless exact evidence requires rejection. Boundary: 106
roadmaps (operator-authorized extension past the 30–50 norm for the
internal-hardening suite and route-expansion intake).
