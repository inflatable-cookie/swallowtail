       child-process behavior for `--sandbox` / `GEMINI_SANDBOX`.
3. [ ] Build a closed version/platform/backend/value table. Prove which exact

       installing a backend, reading credentials, or mutating host state.

       backend, containment, or isolation claim.

- [ ] omission and enterprise API-key access stay exact; consumer login stays out
- [ ] no production code, public API, shared authority, currentness, release,

## Stop Conditions

- sandbox backend/version/platform membership is not closed
- ambient settings or environment can override the caller selection
- activation cannot be confirmed prompt-free or requires backend installation
- proof needs login, credential, provider prompt, paid work, install/update,
  host configuration mutation, or a shared-contract change

## Out Of Scope

Gemini CLI ACP or Live, thinking, output limits, consumer-account login,
portable containment guarantees, production binding, live provider work,
currentness, release, merge, shared closeout, rollover, or g04 closure.
