## Goal

Freeze the exact Kimi Code ACP source milestone and session-option behavior for
catalogue-declared `xhigh` and `max`, then define the smallest qualified
version/value set that can reuse Swallowtail's negotiated reasoning contract.

## Method

1. Freeze current official Kimi Code configuration documentation for
   `support_efforts`, `default_effort`, runtime selection, fallback, and
   model-specific support. Record retrieval dates, complete specimen digests,
   and keep it distinct from exact npm evidence.
2. Re-acquire or verify official exact npm/source artifacts across every
   decisive milestone inside qualified `0.29.0..=0.38.0`. Start from Research
   086/165/179 identities. Record tag, peeled commit, package integrity, and
   complete digests for model projection, config-option construction,
   `session/set_config_option`, provider application, confirmation, and error
   paths.
3. Identify the first exact version whose ACP `thinking` option projects the
   current model's `support_efforts` and whose set path accepts, preserves, and
   returns `xhigh` and `max`. Diff adjacent qualified versions; do not infer the
   floor from the current claim's broad behavior revision.
4. Freeze exact option id, type, category, current value, row construction,
   ordering, duplicates, blank/foreign values, default resolution, boolean
   models, always-thinking models, model changes, and config-option updates.
5. Trace `xhigh` and `max` separately from catalogue declaration through
   session-open snapshot, caller request, adapter/server selection, underlying
   SDK/provider intent, response snapshot, and effective current value.
   Distinguish advertisement, request, dispatch, acceptance, effectiveness,
   and observation.
6. Classify clamping, aliasing, nearest-value fallback, inherited/default
   effort fallback, unsupported configured values, stale selection after model
   change, missing option, ambiguous option, malformed rows, foreign values,
   provider rejection, confirmation drift, disconnect, deadline, and cleanup.
7. Classify open, load, resume, import, attachment recovery, cancellation, and
   fresh restoration separately. Only new-session selection is a candidate.
8. Decide the exact compatibility revision and version segment. Preserve
   legacy boolean and declared `low|medium|high` behavior; do not let
   `UnverifiedNewer` inherit a newly proved extended-effort guarantee silently.
9. Replace Research 207's reservation with source-backed version/value,
   lifecycle, failure, and compatibility dispositions plus a deliver-now table
   or honest empty set.

Current official public docs, exact public npm/source artifacts, existing
fixtures, and secret-free local source/unit probes are authorized. Do not
install or launch Kimi, mutate OAuth/login state, inspect credentials or account
state, send a provider prompt, perform external inference, or incur paid work.
