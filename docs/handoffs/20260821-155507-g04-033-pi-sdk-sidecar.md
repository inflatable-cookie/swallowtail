## What This Thread Was Doing

The orchestrator merged the current route stack, triaged new route research,
and moved g04 onto route-local feature completion. Pi became the immediate
problem because its production RPC route cannot bind a persisted session to the
host-leased working resource. Research 181 established that Pi's official SDK
does expose the missing seam, but as a TypeScript package it needs an honestly
identified Node sidecar rather than an in-process Rust SDK claim.

The planning base promotes that boundary into Contracts 019 and 029 and
compiles g04.033. This is the handoff from the orchestrator to one bounded
implementation thread. It stands alone; no copied transcript or second prompt
is needed.

## Why It Matters

Pi's SDK gives Swallowtail access to the full maintained runtime surface,
including safe cwd override, effective cwd observation, and typed messages.
That can close a real per-route feature failure: persistent load and resume.
The route still needs exact process, package, configuration, resource, and
cleanup truth. A casual wrapper would replace one RPC limitation with an
unversioned private protocol and ambient Node behavior.
