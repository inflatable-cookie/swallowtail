## Goal

Close the route-local family with deterministic proof of exact effort
dispatch, selected-model agreement, fail-closed fallback handling, omission,
lifecycle, documentation, and API truth.

## Work

1. Freeze fixtures for every Research 210 exact row, omission, inherited-
   environment conflict, malformed/unsupported value, missing model support,
   and any qualified confirmation or failure shape.
2. Prove exact child arguments and environment for every admitted value and
   byte-equivalent omission for the existing route.
3. Prove a selected value cannot be replaced by default, alias, clamp, ambient
   config, a different model, or a different provider before child creation.
4. Prove only the claim layers admitted by Research 210. Do not infer effective
   reasoning from output quality, tokens, prose, or successful fixture parsing.
5. Prove stream-json emits no public thought content or reasoning-summary
   activity and that diagnostics reveal no raw configuration surface.
6. Prove access, retention, managed recovery, retry, cancellation, deadline,
   terminal, and cleanup behavior remains unchanged.
7. Update the Kimi prepared guide, feature matrix when warranted, package API
   baseline, Research 210, milestone/cards, triage inventory, programme,
   reserved closeout, indexes, and sole Next Task.
8. Run the named package, route, docs, API, example, doctor, and diff gates.

## Acceptance Criteria

- [ ] every delivered exact row has deterministic model/value dispatch proof
- [ ] no row prepares outside Research 210
- [ ] fallback, substitution, shadowing, and model disagreement fail closed
- [ ] omission retains prior process and lifecycle behavior
- [ ] no thought material or unsupported activity claim becomes public
- [ ] recovery, retention, access, retry, cancellation, and cleanup stay exact
- [ ] guide and matrix state exact values, versions, models, and claim strength
- [ ] no sibling route, shared contract/runtime, currentness, release, or
      generation state changes
- [ ] `cargo fmt -p swallowtail-adapter-kimi` passes
- [ ] `effigy validate:focused swallowtail-adapter-kimi` passes
- [ ] `effigy package:verify-affected swallowtail-adapter-kimi` passes
- [ ] `effigy check:examples`, `effigy qa:routes`, `effigy qa:northstar`,
      relevant index gates, `effigy package:api`, and `git diff --check` pass
- [ ] `effigy doctor` does not worsen the inherited 378-finding baseline

## Stop Conditions

- fixtures contradict Research 210 or exact fail-closed dispatch is unproved
- public thought leakage, lifecycle regression, or implicit fallback remains
- acceptance requires live provider work, shared authority, currentness
  movement, or generation closure

## Out Of Scope

- another Kimi route/feature, live inference, release, merge, rollover, or g04
  closure
