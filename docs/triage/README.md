# Triage

Unresolved leads: observations, ideas and questions not yet settled. Triage is
never authority. Promote a lead into knowledge, the plan or a question, or
delete it.

Name one note per issue `YYYYMMDD-HHMMSS-<slug>.md` (older notes are dated by
issue). Update a note in place as the issue develops; edit a partially
promoted note down to its unresolved remainder. Git history keeps provenance
after a note is removed. If a note's destination or removal is unclear, ask
the operator before changing it.
