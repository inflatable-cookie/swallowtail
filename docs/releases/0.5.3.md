`0.5.3` is a coordinated pre-1.0 patch over immutable `v0.5.2`. It fixes
registered-tool courier response waiting while preserving the exact SDK, native,
Node, sidecar wire, and route qualification points. The 40-package set and 50
production routes are unchanged.

## Correction

The Contract 063 kernel remains the sole owner of caller, per-call, and optional
lease deadlines. The courier no longer applies the ten-second opening timeout
to a pending call. It waits for a settled host response with a 65-second
transport-stall backstop above the kernel's 60-second maximum call duration.
The backstop only fails closed on a broken or stalled transport; it does not
create another approval or call deadline. Connection acquisition and readiness
keep their existing ten-second/open-remainder limits.

The courier returns a settled call error once when the HTTP response carries a
valid JSON-RPC outcome for the pending request id. That call error does not
terminate a valid connection, so later calls can use the same server. A
mismatched, malformed, partial, oversized, or stalled response fails closed;
the courier never reconnects, retries, replays, or associates a late response
with another call. Request and response byte bounds, HTTP header bounds, one
outstanding call, lease expiry, revocation, and joined cleanup remain in force.

The host dispatcher must continue to cooperate with cancellation and settle
within the declared deadline. If work cannot be joined, its failed ownership
and cleanup truth remain visible; no later work silently inherits that lease.

All 40 workspace packages move together to `0.5.3`. Internal dependency edges
change only from the coordinated `^0.5.2` requirement to `^0.5.3`; external
dependency versions and lock sources do not move. The semantic public API has
no additions or removals, the route inventory matches `v0.5.2`, and the Rust
`1.95.0` floor and `publish = false` posture remain unchanged. This bounded
behavioral correction is patch-compatible under Contract 036.

The SDK remains `0.3.259`, native binary `2.1.259`, Node `22.23.2`, SDK sidecar
wire `swallowtail-claude-agent-sdk-jsonl-v1`, courier wire v1, and MCP protocol
`2025-11-25`. The SDK sidecar source remains byte-identical to `v0.5.2` at
SHA-256 `4bdf23f838f367ba04ff925411f90dc19a5f86f6de94127adcb07d85629d04dd`;
its embedded source identity continues to derive from the coordinated package
version. The public API, route, and external dependency baselines remain
unchanged; new candidate inventories record the coordinated package version.
