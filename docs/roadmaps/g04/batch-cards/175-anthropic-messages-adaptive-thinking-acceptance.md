## Goal

Close the route-local family with deterministic proof of exact adaptive
thinking dispatch, private stream handling, tool-loop replay, effort
composition, privacy, lifecycle, and documentation truth.

## Work

1. Freeze fixtures for every Research 209 delivered row, thinking absence,
   ordinary thinking blocks, redacted blocks, multiple consecutive blocks,
   signature completion, tool use, final text, and later turns.
2. Prove exact adaptive/omitted request bytes and byte-identical omission on
   both structured and direct-continuation profiles.
3. Prove composition with effort omission and every admitted
   `low|medium|high|xhigh|max` value without defaults, clamps, or shared claims.
4. Prove complete ordered private replay before tool use, exact correlation,
   later-turn history, per-attempt usage, terminal truth, and no implicit
   attempt.
5. Prove missing signature/data, altered/reordered/duplicate blocks, invalid
   deltas, unknown semantic blocks, overflow, provider 400, disconnect,
   cancellation, deadline, close, and cleanup failure.
6. Prove thought text, signature, redacted data, and raw blocks remain absent
   from events, activity, terminal output, callback exchange, prepared
   evidence, serialization, formatting, diagnostics, and debug observation.
7. Prove zeroization and route/session binding on completion, failure,
   invalidation, close, and fresh restoration.
8. Update the Anthropic prepared guide, feature matrix when warranted,
   package API baseline, Research 209, milestone/cards, triage inventory,
   programme, reserved closeout, indexes, and sole Next Task.
9. Run the named package, route, docs, API, example, doctor, and diff gates.

## Acceptance Criteria

- [ ] every delivered exact row has deterministic request and stream proof
- [ ] adaptive thinking never prepares outside Research 209
- [ ] private replay is complete, exact, ordered, bounded, and correlated
- [ ] omission and effort composition retain prior behavior
- [ ] no private thought material reaches any public or diagnostic surface
- [ ] malformed or contradictory private state fails closed without fallback
- [ ] cancellation, deadline, terminal, restoration, and cleanup remain exact
- [ ] guide and matrix distinguish adaptive thinking from effort and disclosure
- [ ] no sibling route, shared contract/runtime, currentness, release, or
      generation state changes
- [ ] `cargo fmt -p swallowtail-adapter-anthropic` passes
- [ ] `effigy validate:focused swallowtail-adapter-anthropic` passes
- [ ] `effigy package:verify-affected swallowtail-adapter-anthropic` passes
- [ ] `effigy check:examples`, `effigy qa:routes`, `effigy qa:northstar`,
      relevant index gates, `effigy package:api`, and `git diff --check` pass
- [ ] `effigy doctor` does not worsen the inherited 378-finding baseline

## Stop Conditions

- fixtures contradict Research 209 or exact private replay cannot be proved
- a public thought leak, unbounded state, lifecycle regression, or implicit
  retry remains
- acceptance requires live provider work, shared contract/runtime change,
  currentness movement, or generation closure

## Out Of Scope

- another Anthropic feature, readable thinking summaries, live inference,
  release, merge, generation rollover, or g04 closure
