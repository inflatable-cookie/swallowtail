bridge. `OperationBridgeListener::close` now wakes the read side of each live
accepted stream before joining, while leaving the write side available to an
in-flight handler. The connection thread retires its wake clone on exit, so
peer end-of-stream timing remains unchanged and `IO_TIMEOUT` remains the
