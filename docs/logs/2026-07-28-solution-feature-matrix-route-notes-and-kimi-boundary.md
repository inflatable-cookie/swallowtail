## Kimi

row now says explicitly that `kimi-code.headless` does not select reasoning.

The supported route is TypeScript `@moonshot-ai/kimi-code`. Exact `0.29.2`
and current main expose no headless thinking input. The documented
`--thinking` and `--no-thinking` flags belong to the older Python `kimi-cli`
distribution. Shared branding and command name do not make it a newer
`kimi-code.executable` version segment.

Supporting Python `kimi-cli` would require a separate executable identity,
version axis, preparation evidence, and route decision. That possibility stays
in backlog and does not add a new matrix row before promotion.
