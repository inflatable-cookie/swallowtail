# Swallowtail 0.3.2

Status: local candidate 2026-08-11
Distribution: annotated Git tag only after exact CI acceptance
Registry: not published
GitHub Release: not created

`v0.3.2` is a compatible source patch over immutable `v0.3.1`. It adds two
separately selectable packages and two production routes while preserving the
Rust `1.95.0` floor, Apple Silicon macOS verified target, source-only
distribution, and existing public and guaranteed-behavior boundaries.

## Install

After exact CI acceptance and tag creation, use the canonical repository and
same exact tag for every direct dependency:

```toml
[dependencies]
swallowtail-core = { git = "https://github.com/inflatable-cookie/swallowtail", tag = "v0.3.2" }
swallowtail-runtime = { git = "https://github.com/inflatable-cookie/swallowtail", tag = "v0.3.2" }
swallowtail-host-local = { git = "https://github.com/inflatable-cookie/swallowtail", tag = "v0.3.2" }
swallowtail-adapter-codex = { git = "https://github.com/inflatable-cookie/swallowtail", tag = "v0.3.2" }
```

Do not use the candidate tag until canonical CI and exact tag identity are
recorded here. Never mix tags, branches, paths, registry placeholders, or
unreviewed revisions in one consumer graph.

## Compatibility

No intentional breaking API or guaranteed-behavior change is selected.
Consumers on `v0.3.1` can move every direct Swallowtail dependency to
`v0.3.2` in one edit.

Unchanged boundaries:

- Rust `1.95.0` floor and Apple Silicon macOS verified target
- exact provider and harness qualification remains separate from package semver
- source-only distribution with every crate retaining `publish = false`
- prompts, tools, callbacks, routing, retry, fallback, persistence, billing,
  and product policy remain downstream

## Upgrade And Rollback

To upgrade, change every direct dependency to `v0.3.2` in one edit, update the
consumer lock file, confirm every Swallowtail package resolves from the same
tag, and run deterministic integration checks.

To roll back, restore every direct dependency to `v0.3.1` and restore the
previous lock file in the same change. Never move or recreate either tag.

## Known Limits

- no crates.io packages, GitHub Release assets, binaries, sidecars, installers,
  or model artifacts are distributed
- the Claude Agent ACP npm sidecar remains an application-local prerequisite
- Claude Code response-only is exact-version `2.1.227`, text-only, tool-free,
  and carries no JSON or schema guarantee
- Command Code is qualified at exact npm `1.15.1`
- authenticated provider and live-harness probes remain operator-gated and
  outside deterministic release preparation
