# Swallowtail 0.3.3

Status: local candidate 2026-08-19
Distribution: annotated Git tag `v0.3.3` is not created
Registry: not published
GitHub Release: not created

`v0.3.3` is a compatible source patch over immutable `v0.3.2`. It adds ten
separately selectable packages and eleven production routes while preserving
the Rust `1.95.0` floor, Apple Silicon macOS verified target, source-only
distribution, and existing public and guaranteed-behavior boundaries.
OpenHands Agent Server is included as a package without a production route.

## Install

Use the canonical repository and same exact tag for every direct dependency:

```toml
[dependencies]
swallowtail-core = { git = "https://github.com/inflatable-cookie/swallowtail", tag = "v0.3.3" }
swallowtail-runtime = { git = "https://github.com/inflatable-cookie/swallowtail", tag = "v0.3.3" }
swallowtail-host-local = { git = "https://github.com/inflatable-cookie/swallowtail", tag = "v0.3.3" }
swallowtail-adapter-codex = { git = "https://github.com/inflatable-cookie/swallowtail", tag = "v0.3.3" }
```

Never mix tags, branches, paths, registry placeholders, or unreviewed revisions
in one consumer graph.

- OpenHands Agent Server identity, driver, and prepared facade without a
  production route
- Claude Code response-only protocol-compatibility policy over
  `2.1.227..=2.1.235`

  Antigravity, Kimi Code, Qwen, Grok, Oh My Pi, Pi, Ollama, and Cursor

- upgrade transitive `h2` to `0.4.17` for RUSTSEC-2026-0258

## Compatibility

No intentional breaking API or guaranteed-behavior change is selected.
Consumers on `v0.3.2` can move every direct Swallowtail dependency to
`v0.3.3` in one edit.

Unchanged boundaries:

- Rust `1.95.0` floor and Apple Silicon macOS verified target
- exact provider and harness qualification remains separate from package semver
- source-only distribution with every crate retaining `publish = false`
- prompts, tools, callbacks, routing, retry, fallback, persistence, billing,
  and product policy remain downstream

## Upgrade And Rollback

To upgrade, change every direct dependency to `v0.3.3` in one edit, update the
consumer lock file, confirm every Swallowtail package resolves from the same
tag, and run deterministic integration checks.

To roll back, restore every direct dependency to `v0.3.2` and restore the
previous lock file in the same change. Never move or recreate either tag.

## Known Limits

- no crates.io packages, GitHub Release assets, binaries, sidecars, installers,
  or model artifacts are distributed
- the Claude Agent ACP npm sidecar remains an application-local prerequisite
- OpenHands Agent Server is not a production route
- additive harness routes are qualified-only at their frozen identities
- authenticated provider and live-harness probes remain operator-gated and
  outside deterministic release preparation
