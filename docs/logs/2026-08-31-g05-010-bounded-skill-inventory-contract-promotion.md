## Settled Boundary

- runtime owns portable records and pure assembly; the execution host owns
  root approval, canonical traversal, bounded reads, cancellation, and joined
  cleanup
- adapters declare exact distribution sources and versioned decoders; they do
  not scan host package trees
- fixed library maxima cover roots, depth, visits, candidates, bytes, rows,
  notes, and public text
- same-root symlinks require canonical containment; escapes, cycles,
  unreadable entries, malformed metadata, and limits preserve partial truth
- snapshots bind exact source, host, resource, instance, version, decoder,
  limits, and observation identities; rescans replace rather than mutate them
- rows are metadata-only; raw paths, bodies, and public body digests stay out
- duplicate names remain separate and inventory never selects an effective
  winner
- Contract 058 composition requires an exact same-context adapter mapping;
  absence from incomplete effective evidence remains unknown
- cancellation, deadline, host failure, or cleanup failure publishes no
  successful snapshot
