## Problem

Command Code exposes a machine-readable headless NDJSON AgentEvent stream.
Swallowtail has no route for it. Research 116 qualifies exact npm release
`1.15.1` for one dedicated installed headless structured-run driver.

## Generation Runway

Advance g03's high-value installed-harness goal. Command Code qualifies because
it has authenticated machine evidence, thinking/tool/usage activity, typed
failures including credit exhaustion, and fits existing structured-run
contracts without inventing ACP or a new kernel boundary.

  skills from the first route
