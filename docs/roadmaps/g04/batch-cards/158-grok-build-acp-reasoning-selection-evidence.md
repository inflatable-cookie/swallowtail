## Goal

Freeze the exact Grok Build ACP reasoning-option surface and define the smallest
version/model/value set that can map to portable `ReasoningSelection` with
effective confirmation before readiness or first prompt.

## Method

1. Freeze the current official Grok Build CLI/ACP documentation and changelog
   statements for effort selection on new and resumed sessions. Record retrieval
   dates, stable URLs, complete specimen digests, and contradictions.
2. Inspect exact official published package/source artifacts for deprecated
   `0.2.114..=0.2.117` and maintained `1.0.4..=1.0.5` when available. Freeze
   decisive ACP session-open, config-option, value, model, update, and error
   paths with source identity and digests.
3. Reconcile existing secret-free Research 130/163 handshakes and compatibility
   fixtures. Identify where `low|medium|high` and `xhigh` were advertised and
   freeze the complete bounded `session/new` result or update shape.
4. Determine the exact adapter-private option id, category, raw values,
   current/default value, ordering, duplicate/ambiguity rules, and model binding.
   Do not treat labels, CLI flags, or array position as protocol ids.
5. Freeze one exact `session/set_config_option` request, response, and any
   `config_option_update` confirmation. Decide which selected surface proves
   effective value and whether a response without a confirming snapshot is
   sufficient under Contract 034.
6. Classify interactive new session, operation-private structured-run session,
   attachment recovery, load, and resume separately. Selection on one lifecycle
   does not imply another.
7. Classify omission, unsupported value, malformed snapshot, duplicate option,
   missing model, foreign update, rejected request, missing confirmation,
   effective mismatch, later drift, disconnect, timeout, and session allocation
   followed by failure.
8. Decide exact qualified and `UnverifiedNewer` inheritance, plus behavior,
   driver, claim, and configured-instance revision posture. Do not edit Contract
   029 or production code on this card.
9. Replace Research 204's reservation with source-backed version/model/value,
   lifecycle, application-state, failure, and cleanup dispositions plus a
   deliver-now table or honest empty set.

Current public documentation, existing no-prompt handshake evidence, and
secret-free exact package/source inspection are authorized. Do not install or
authenticate Grok, inspect account state, capture credentials, send a provider
prompt, or perform paid work.

- values are model-defaulted, clamped, aliased, substituted, or unconfirmed
- the option cannot be selected on a new session before first prompt
- qualification needs authenticated prompt output, account inspection, generic
  provider configuration, a contract change, or currentness movement
