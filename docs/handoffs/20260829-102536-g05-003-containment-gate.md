## Why It Matters

The watcher feature exists to make background work dependable, not merely
observable. Weakening the contract to “kill the process group and report an
orphan if noticed” would preserve the exact failure the feature is meant to
remove. Capability gating keeps the portable lifecycle useful while letting
future Windows Job Object, Linux cgroup, consumer supervisor, container, or VM
backends prove containment independently.
