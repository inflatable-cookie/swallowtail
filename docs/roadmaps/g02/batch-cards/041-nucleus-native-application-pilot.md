## Objective

Prove the current Swallowtail candidate through Nucleus's normal native
catalogue and Agent Chat path before sustained or writable work.

## Entry Gates

- card 040 complete
- Nucleus companion card 010 complete
- unrelated Nucleus work checkpointed or non-overlapping
- isolated desktop state root, normal Agent Chat cancellation, proof deadline,
  and native Effigy proof selector available
- exact runtime, executable, access, topology, fixture, and workload tuple
  frozen
- exact 15-attempt authenticated Codex ceiling approved — open
- live test data contains no private or durable user material

## Scope

1. Verify the frozen source, executable, model, access, topology, and fixture
   tuple before every launch.
2. Run 3 catalogue attempts across 3 native launches and 2 full restarts.
3. Run the 12 planned Agent Chat attempts: 6 ordinary successes, 3 read-only
   callback successes, 1 cancellation, 1 controlled deadline, and 1
   post-restart recovery success.
4. Prove 6 joined app-server lifecycles, no parallel turns, and no more than 3
   live children.
5. Capture the safe lifecycle, usage, rate, cleanup, persistence, and
   correlation evidence defined by card 040.
6. Use no more than 3 exact-scenario reruns and stop at 15 turns or 60 minutes.
7. File defects by Swallowtail or Nucleus ownership.
