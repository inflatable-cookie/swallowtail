## Intent and boundary

Establish Swallowtail as an independent project: portable provider-neutral
contract and runtime kernels, real driver shapes, and first consumer and
cross-adapter adoption — deliberately without stabilizing the public API.
Boundary: 49 roadmaps (48 completed, one backlog move of the
externally blocked Grok lane). Operator approved closure on 2026-07-24.

## Shipped outcomes

- **Standalone authority and repository QA** — independent project identity,
  ownership and dependency direction settled before any provider code.
- **Portable contract kernel** — identity, capability, model, reference,
  event, and error vocabulary with deterministic conformance fixtures.
- **Runtime kernel** — provider-neutral records, preflight, lifecycle, and
  host services; async runtime with synthetic cross-shape conformance.
- **Proof drivers** — separate Codex exec and app-server drivers, then
  Soundcheck, Nucleus, OpenCode HTTP, Anthropic direct inference, Gemini ACP,
  attached and owned llama.cpp, xAI WebSocket, Kimi ACP, Bedrock catalogue,
  OpenAI background, Claude managed-agent remote harness, Qwen headless,
  direct-provider codecs, Kimi K3, realtime media (OpenAI, Gemini Live),
  Pi RPC, DeepSeek continuation, Ollama attach, and remote ACP transport.
- **Consumer adoption** — Soundcheck and Nucleus readiness lanes and the
  first real Soundcheck consumer feedback loop.
- **Compatibility foundations** — maintained interface-version windows,
  qualified support with newer-version execution, and attach-only native
  runtime truth.
